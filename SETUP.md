# Инструкции по установке и запуску

## Предварительные требования

### 1. Установка Node.js
Скачайте и установите Node.js с официального сайта: https://nodejs.org/

Рекомендуется версия 18.x или выше.

### 2. Проверка установки
После установки откройте терминал и выполните:
```bash
node --version
npm --version
```

## Установка и запуск проекта

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```

### 3. Открытие в браузере
После запуска откройте http://localhost:5173 в браузере

## Альтернативные способы запуска

### Использование Yarn
Если у вас установлен Yarn:
```bash
yarn install
yarn dev
```

### Использование pnpm
Если у вас установлен pnpm:
```bash
pnpm install
pnpm dev
```

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`.

## Возможные проблемы

### Ошибка "npm не распознан"
- Убедитесь, что Node.js установлен корректно
- Перезапустите терминал после установки
- Проверьте переменные среды PATH

### Ошибки зависимостей
```bash
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### Проблемы с портом
Если порт 5173 занят, Vite автоматически предложит другой порт.

## Структура проекта после установки

```
Timer/
├── node_modules/        # Зависимости (создается после npm install)
├── dist/               # Собранные файлы (создается после npm run build)
├── src/                # Исходный код
├── package.json        # Конфигурация проекта
├── vite.config.ts      # Конфигурация Vite
└── README.md           # Документация
```
