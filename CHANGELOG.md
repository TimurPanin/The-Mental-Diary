# Changelog

## [2.0.0] - 2024-01-XX

### 🎯 Основные улучшения

#### 📁 Реорганизация структуры проекта
- **Новая структура папок:**
  - `src/components/` - React компоненты
  - `src/styles/` - стили, темы, анимации
  - `src/hooks/` - кастомные хуки
  - `src/utils/` - утилиты и функции
  - `src/constants/` - константы приложения
  - `src/types/` - TypeScript типы
  - `src/tests/` - тесты
  - `src/examples/` - примеры использования
  - `docs/` - документация

#### 🎨 Улучшения адаптивности
- **Медиа-запросы для всех компонентов:**
  - Мобильные устройства (≤480px)
  - Планшеты (≤768px)
  - Десктопы (>768px)
- **Адаптивные размеры шрифтов**
- **Гибкая сетка для отображения времени**
- **Адаптивные кнопки управления**

#### 🔧 Рефакторинг кода
- **Вынесение логики в кастомный хук `useTimer`**
- **Создание утилит `timerUtils`**
- **Централизованная тема в `theme.ts`**
- **Глобальные стили в `GlobalStyles.ts`**
- **Переиспользуемые анимации в `animations.ts`**
- **Константы в `constants/index.ts`**

#### 🧪 Тестирование
- **Настройка Jest для тестирования**
- **Тесты для основных компонентов**
- **Покрытие кода тестами**
- **Моки для Framer Motion**

#### 📚 Документация
- **API документация в `docs/API.md`**
- **Примеры использования в `src/examples/`**
- **Обновленный README с новой структурой**
- **Подробное описание компонентов**
