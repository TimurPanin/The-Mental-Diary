# Ментальный дневник - Итоговое описание проекта

## 🎯 Цель проекта

Создание современного веб-приложения для отслеживания психического здоровья, которое помогает пользователям:
- Формировать привычку самонаблюдения
- Отслеживать настроение и эмоции
- Получать мягкую поддержку через AI-подсказки
- Анализировать тренды своего психического состояния

## ✅ Реализованные функции (MVP)

### 1. Регистрация и анонимность
- ✅ Анонимный вход без указания личных данных
- ✅ Опциональная регистрация с email
- ✅ Локальное хранение данных пользователя

### 2. Записи в дневник
- ✅ Текстовые записи с описанием дня
- ✅ Выбор настроения через эмодзи (10 вариантов)
- ✅ Оценка уровня энергии по шкале 1-10
- ✅ Оценка уровня стресса по шкале 1-10
- ✅ Система тегов для категоризации

### 3. AI-подсказки
- ✅ Поддерживающие сообщения для новых пользователей
- ✅ Вопросы для размышления для опытных пользователей
- ✅ Автоматическая генерация подсказок
- ✅ Возможность отклонить подсказки

### 4. Аналитика и графики
- ✅ Статистика средних показателей
- ✅ График тренда настроения за 30 дней
- ✅ Подсчет дней подряд ведения дневника
- ✅ Визуализация данных с помощью Recharts

### 5. Безопасность и приватность
- ✅ AES шифрование всех данных
- ✅ Локальное хранение в браузере
- ✅ Отсутствие передачи данных на серверы
- ✅ Полная анонимность пользователей

## 🛠 Техническая реализация

### Архитектура
- **Frontend**: React 18 + TypeScript
- **Сборка**: Vite
- **Стилизация**: Styled Components
- **Анимации**: Framer Motion
- **Состояние**: Zustand
- **Графики**: Recharts
- **Безопасность**: CryptoJS

### Структура компонентов
```
App.tsx (Главный компонент)
├── LoginScreen (Экран входа)
├── JournalEntryForm (Форма записи)
├── JournalEntryList (Список записей)
└── Analytics (Аналитика)
```

### Управление данными
- **Store**: Zustand с персистентностью
- **Хранение**: localStorage с шифрованием
- **Валидация**: TypeScript + runtime проверки
- **Аналитика**: Автоматический расчет метрик

## 🔒 Безопасность

### Принципы безопасности
- **Приватность**: Все данные хранятся локально
- **Шифрование**: AES шифрование всех данных
- **Анонимность**: Не требуется личная информация
- **Контроль**: Пользователь полностью контролирует свои данные

### Техническая реализация
```typescript
// Шифрование данных
const encryptedData = CryptoJS.AES.encrypt(data, ENCRYPTION_KEY);

// Локальное хранение
localStorage.setItem('journal-data', encryptedData);
```

Приложение готово к использованию после установки Node.js и запуска команд:
```bash

npm run dev
```
