# Руководство по использованию

## Первый запуск

### 1. Вход в систему
- Откройте приложение в браузере
- Выберите "Начать анонимно" для быстрого старта
- Или введите email для создания аккаунта

### 2. Знакомство с интерфейсом
После входа вы увидите:
- **Заголовок** с логотипом и навигацией
- **Подсказка дня** - AI-совет для размышления
- **Список записей** (изначально пустой)
- **Кнопка "+"** для добавления новой записи

## Создание записей

### 1. Добавление новой записи
- Нажмите на кнопку "+" в правом нижнем углу
- Заполните форму записи:
  - **Текст** - опишите, как прошел ваш день
  - **Настроение** - выберите эмодзи
  - **Энергия** - уровень энергии по шкале 1-10
  - **Стресс** - уровень стресса по шкале 1-10
  - **Теги** - добавьте теги для категоризации (необязательно)

### 2. Сохранение записи
- Нажмите "Сохранить запись"
- Запись появится в списке с датой и временем

## Навигация

### Вкладки:
- **Дневник** - просмотр и редактирование записей
- **Аналитика** - графики и статистика
- **Настройки** - настройки приложения

### Действия с записями:
- **Редактировать** - нажмите иконку карандаша
- **Удалить** - нажмите иконку корзины
- **Просмотр** - кликните на запись для детального просмотра

## Аналитика

### Доступные метрики:
- **Среднее настроение** - общий показатель за все время
- **Средняя энергия** - уровень энергии
- **Средний стресс** - уровень стресса
- **Дни подряд** - количество последовательных записей

### Графики:
- **Тренд настроения** - изменения за последние 30 дней
- **Распределение** - гистограмма настроения за неделю

## AI-подсказки

### Типы подсказок:
- **Поддерживающие сообщения** - для новых пользователей
- **Вопросы для размышления** - для опытных пользователей

### Получение подсказки:
- Нажмите на иконку колокольчика в заголовке
- Или дождитесь автоматической генерации

## Безопасность и приватность

### Локальное хранение:
- Все данные хранятся в вашем браузере
- Никакая информация не передается на серверы
- Данные зашифрованы с помощью AES

### Анонимность:
- Можно использовать без регистрации
- Email необязателен
- Нет отслеживания пользователей

## Советы по использованию

### Регулярность:
- Старайтесь вести дневник ежедневно
- Выберите удобное время (вечером или утром)
- Не пропускайте дни для лучшей аналитики

### Качество записей:
- Пишите подробно о событиях дня
- Обращайте внимание на эмоции
- Используйте теги для категоризации

### Анализ данных:
- Регулярно просматривайте аналитику
- Обращайте внимание на тренды
- Используйте подсказки для размышлений

## Экспорт данных

### Резервное копирование:
- Данные автоматически сохраняются в браузере
- Для переноса на другое устройство используйте экспорт
- Функция экспорта будет добавлена в следующей версии

## Устранение неполадок

### Проблемы с сохранением:
- Проверьте, что все обязательные поля заполнены
- Убедитесь, что браузер поддерживает localStorage
- Попробуйте очистить кэш браузера

### Проблемы с отображением:
- Обновите страницу
- Проверьте, что JavaScript включен
- Попробуйте другой браузер

### Потеря данных:
- Данные хранятся локально в браузере
- При очистке данных браузера записи могут быть потеряны
- Рекомендуется регулярное резервное копирование

## Поддержка

### Получение помощи:
- Создайте Issue в GitHub репозитории
- Опишите проблему подробно
- Приложите скриншоты, если необходимо

### Важные замечания:
- Приложение не заменяет профессиональную медицинскую помощь
- При серьезных проблемах с психическим здоровьем обратитесь к специалисту
- Данные не передаются третьим лицам
