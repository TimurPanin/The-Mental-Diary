# Инструкции по деплою на GitHub Pages

## Настройка GitHub Pages

1. Перейдите в настройки вашего репозитория на GitHub
2. Найдите раздел "Pages" в левом меню
3. В разделе "Source" выберите "GitHub Actions"
4. Это позволит использовать автоматический деплой через workflow

## Альтернативная настройка (если нужна ветка gh-pages)

Если вы хотите использовать ветку `gh-pages`:
1. В разделе "Source" выберите "Deploy from a branch"
2. Выберите ветку `gh-pages` и папку `/ (root)`
3. Нажмите "Save"

## Автоматический деплой

Проект настроен для автоматического деплоя через GitHub Actions. При каждом пуше в ветку `main` будет происходить автоматическая сборка и деплой.

## Ручной деплой

Если нужно выполнить деплой вручную:

1. Установите зависимости:
```bash
npm install
```

2. Соберите проект:
```bash
npm run build
```

3. Загрузите содержимое папки `dist` в ветку `gh-pages`
